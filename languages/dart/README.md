# Dart

Dart is a client-optimized language for fast apps on any platform. Developed by Google, it's the primary language for Flutter development and offers modern programming features with clean, readable syntax.

## Core Concepts

### Basic Syntax and Types
- **[Dart Syntax Guide](./dart-syntax.md)**: Comprehensive language syntax and features
- **Variables and Data Types**: Numbers, Strings, Booleans with null safety
- **Collections**: Lists, Maps, Sets with modern operations
- **Control Flow**: If, loops, switch with pattern matching

### Object-Oriented Programming
- **[Classes and Objects](./classes-and-objects.md)**: Everything is an object in Dart
- **[Inheritance and Polymorphism](./inheritance-and-polymorphism.md)**: Code reusability patterns
- **[Mixins](./mixins.md)**: Multiple inheritance capabilities
- **[Abstract Classes](./abstract-classes.md)**: Interface-like behavior

### Functions and Methods
- **Function Syntax**: Named and anonymous functions
- **Optional Parameters**: Positional and named parameters
- **Higher-order Functions**: Functions as first-class citizens
- **Closures**: Lexical scoping and closure capture

### Asynchronous Programming
- **Futures**: Promise-like asynchronous operations
- **Async/Await**: Modern async syntax
- **Streams**: Reactive programming with data streams
- **Isolates**: Concurrent execution model
