# Operating Systems

Documentation and guides for different operating systems and their features.

## Linux Distributions
- [Ubuntu](ubuntu.md) - Popular open-source Linux distribution based on Debian, widely used for servers and desktops

## Windows
- [Windows](windows.md) - Proprietary operating system developed by Microsoft, commonly used for personal computers and servers

## macOS
Apple's proprietary operating system for Mac computers, known for its Unix-like architecture and user-friendly interface
